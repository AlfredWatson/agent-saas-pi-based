# pi-coding-agent TUI 斜杠命令参考

本文基于本机已安装的 `@earendil-works/pi-coding-agent` **0.82.1** 整理。斜杠命令（Slash Commands）是在交互式 TUI 输入框中以 `/` 开头的命令：输入 `/` 可打开补全列表。

> `/skills` **不是**此版本的内置命令。Skill 被发现并加载后，通过 `/skill:<名称>` 调用，例如 `/skill:brave-search`。

## 内置命令

| 命令 | 参数 | 说明 |
| --- | --- | --- |
| `/login` | `[provider]` | 打开认证流程，配置指定或选定模型提供商的 OAuth、订阅或 API Key 凭据。 |
| `/logout` | 无 | 移除由 `/login` 保存的凭据；不会删除环境变量或 `models.json` 中的配置。 |
| `/llama` | 无 | 下载、加载或卸载 llama.cpp router 模型。该能力由 pi 随附的 llama 扩展提供。 |
| `/model` | `[搜索词]` | 打开模型选择器；提供搜索词时按该词筛选。 |
| `/scoped-models` | 无 | 配置哪些模型可通过 `Ctrl+P` 循环切换。 |
| `/settings` | 无 | 打开设置界面，调整思考级别、主题、消息投递方式和传输设置等。 |
| `/resume` | 无 | 从已有会话中选择并恢复。 |
| `/new` | 无 | 开始一个新会话。 |
| `/name` | `<名称>` | 设置当前会话的显示名称。 |
| `/session` | 无 | 显示当前会话文件、ID、消息数、Token 用量和费用信息。 |
| `/tree` | 无 | 浏览会话树，跳转到任意历史节点并从该处继续。 |
| `/trust` | 无 | 为当前项目保存信任决定，供后续会话使用。 |
| `/fork` | 无 | 从先前的一条用户消息创建分支会话。 |
| `/clone` | 无 | 将当前活动分支复制为新的会话。 |
| `/compact` | `[提示词]` | 手动压缩上下文；可提供额外指示以影响摘要内容。 |
| `/copy` | 无 | 将最后一条助手回复复制到剪贴板。 |
| `/export` | `[输出文件]` | 将当前会话导出为 HTML 或 JSONL；不提供路径时由 TUI 选择或使用默认位置。 |
| `/import` | `<JSONL 文件>` | 导入 JSONL 会话文件并恢复该会话。 |
| `/share` | 无 | 将当前会话上传为私有 GitHub Gist，并生成可分享的 HTML 链接。 |
| `/reload` | 无 | 重新加载按键绑定、扩展、Skills、提示模板、主题和上下文文件。 |
| `/hotkeys` | 无 | 显示全部键盘快捷键。 |
| `/changelog` | 无 | 显示版本变更历史。 |
| `/quit` | 无 | 正常退出 pi。 |

## 动态命令

以下命令不构成固定清单；它们取决于当前加载的资源和扩展，在输入 `/` 时会显示在补全中。

| 形式 | 来源 | 说明 |
| --- | --- | --- |
| `/skill:<名称>` | Skill | 调用已发现 Skill，例如 `/skill:brave-search`。没有加载对应 Skill 时不可用。 |
| `/<模板名称>` | Prompt Template | 展开已发现的提示模板并作为消息提交。 |
| `/<扩展命令>` | Extension | 由扩展通过 `pi.registerCommand()` 注册；名称、参数及副作用由扩展决定。 |

## 非斜杠的 TUI 输入命令

下面两种写法也在 TUI 输入框中执行，但它们不是 Slash Commands：

| 写法 | 说明 |
| --- | --- |
| `!<shell 命令>` | 运行 shell 命令，并把输出发送给模型作为上下文。 |
| `!!<shell 命令>` | 运行 shell 命令，但不把输出发送给模型。 |

## 实现中存在但不应作为常规接口依赖的命令

当前实现还处理 `/debug`、`/arminsayshi` 和 `/dementedelves`。它们未列入随包的使用文档，属于调试或彩蛋行为；自动化和产品功能不应依赖它们。

## 查看当前会话的实际命令

命令集合会随扩展和 Skills 改变。因此，最可靠的交互式查看方式是在 TUI 中输入 `/` 并使用补全列表；通过 RPC 集成时，可调用 `RpcClient.getCommands()` 获取当前会话可调用的扩展命令、提示模板和 Skill 命令。
