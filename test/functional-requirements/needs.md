4. 智能体应用开发工具集

1）提供 RAG 系统应用，支持完整的数据处理链路，包含文档解析、分段、向 量化、存储、召回、重排全流程处理。 
2）支持知识图谱能力构建，可基于用户已有数据构建领域知识图谱。 
3）支持自定义文本切分策略，包含按语义切分、固定字符切分及正则匹配切 分。
4）提供对话上下文的持久化存储与历史回溯能力，支持用户会话导出。
5）支持向量数据库的统一纳管，可兼容 Milvus、Chroma、Qdrant 等主流向量 数据库。
6）支持 RAG 效果的自动评估，可自动生成包含召回准确率等维度的评估报告。
7）提供基于基座模型的智能体系统，支持工具绑定与函数调用功能。
8）支持智能体的执行过程可视化，可展示每一步的工具调用、思考过程、中间结果。
9）支持多用户 RAG/Agent 应用部署，不同用户的数据、知识库、应用实例完 全隔离。
10）支持 RAG/Agent 应用与现有业务系统的无缝对接，提供标准化的 API 接 口。

4. 智能体应用开发工具集-性能要求

1）RAG/Agent 应用支持基于不少于 6 种主流大模型搭建，包括 Qwen、DeepSeek、 Llama、Kimi K、MiniMax M、GLM 等，模型版本不低于 2026 年 6 月最新版本，支 持对接各模型主用参量。
2）RAG 系统支持多类型文件内容解析，可处理的数据源类型≥6 种，至少包 30 含 PDF、Word、Excel、PPT、Markdown 等格式。
3）解析与向量化建立索引的速度不小于 200 字/s。
4）RAG 知识库检索模块支持混合搜索（全文检索和向量检索），在公开数据 集上检索召回率≥80%。
5）在公开数据集上，系统检索 Top-5 的命中率≥80%。
6）☆支持最高≥50 万（1M）Tokens 的超长上下文窗口对话管理机制。
7）☆Agent 系统支持多 Agent 协同，最大可支持≥10 个 Agent 同时完成复杂任务。
8）支持 RAG 应用对指定业务领域知识库的管理，可实现知识库的增删改查、 权限控制、版本管理，知识库更新生效时延≤5 分钟。
